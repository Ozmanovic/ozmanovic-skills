# Jargonless

Select the report route from the reader's primary need. Use one report by default.

## Select the route

1. Use **ACT** when the reader mainly needs to perform or verify work.
2. Use **DECIDE** when the reader mainly needs to understand, compare, or approve something.
3. Use **ACT + DECIDE** when safe action depends on important reasoning or tradeoffs.
4. Follow an explicit user request for ACT, DECIDE, hybrid, ASD-STE100, ISO 24495-1, or multiple versions.

Select the route silently. Name the style only when the user asks or the label helps compare outputs.

## ACT

Write an ASD-STE100-inspired operational report.

- Put the decision or result first.
- Use short, active sentences.
- Put one instruction in each numbered step.
- Keep only the reasoning required for correct or safe action.
- Use applicable sections in this order:
  1. Decision or result
  2. Actions or procedure
  3. Evidence to check
  4. Confirmation points
  5. Stop conditions

Use ACT for checklists, runbooks, live-test instructions, implementation handoffs, and concise status reports.

## DECIDE

Write an ISO 24495-1-inspired explanatory report.

- Put the decision or recommendation first.
- Explain why it is the best fit for the reader's goal.
- Compare only realistic alternatives.
- State material tradeoffs, risks, assumptions, and unknowns.
- End with an implementation order or clear next action when applicable.
- Use headings that make the answer easy to find, understand, and use.

Use DECIDE for architecture, business analysis, option comparison, risk review, and recommendations.

## ACT + DECIDE

Write one layered report instead of two repeated reports.

1. Give the decision and immediate actions in an ACT-style opening.
2. Add the rationale, alternatives, and risks in DECIDE-style detail.
3. End with confirmation points or the recommended implementation order.

Use the hybrid route when the reader must act now and also understand why.

## Boundaries

- Keep each fact in one place.
- Include only sections that change the reader's action, understanding, or decision.

## Completion check

Before sending the report, confirm all of these conditions:

- The selected route matches the reader's primary need.
- The decision, result, or recommendation appears at the start.
- The report contains no repeated full-version content unless requested.
- The last paragraph states an explicit next action, confirmation point, or decision.
